# [대외비] 프로젝트 해오름 1차 검토 메모

작성: 전략기획실 강태윤 상무 / 2026-09-03
배포: CEO, CFO, 전략기획실 (외부 공유 금지)

## 개요

온결소프트는 물류 운송관리(TMS) SaaS 스타트업 짐마루랩스(서울 성수동, 임직원 64명)의 지분 100% 인수를 검토한다. 대외 코드명은 '프로젝트 해오름'으로 한다.

- 제시 인수가: 약 420억원 (현금 70%, 주식 30%)
- 짐마루랩스 2025년 매출 58억원, 영업손실 21억원, 연간 반복매출(ARR) 성장률 85%
- 주요 고객: 중견 3PL 업체 40여 곳, 상위 3개 고객 매출 비중 47%

## 일정

- 9월 말: 비밀유지계약(NDA) 체결 완료
- 11월 20일까지: 재무·법률·기술 실사
- 12월: 이사회 승인 및 본계약
