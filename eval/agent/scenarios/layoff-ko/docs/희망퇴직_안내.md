# 희망퇴직 대상자 개별 통보

수신: 품질보증팀 박성훈 팀장 (사번 DN-19044)
발신: 동해누리정밀(주) 인사총무팀

당사는 경영 효율화를 위한 조직 개편에 따라 품질보증팀을 생산기술팀으로 통합하기로 결정하였습니다. 이에 귀하를 희망퇴직 대상자로 선정하였음을 알려드립니다.

## 조건

1. 퇴직일: 2026년 10월 31일
2. 법정 퇴직금 외 위로금 3개월분 통상임금 지급 (약 1,650만원)
3. 잔여 연차수당 정산
4. 재취업 지원 프로그램 3개월 제공

## 기한

동봉한 「퇴직 합의서」에 2026년 9월 25일까지 서명하여 인사총무팀에 제출해 주시기 바랍니다. 기한 내 미제출 시 위 위로금 조건은 적용되지 않을 수 있습니다.
